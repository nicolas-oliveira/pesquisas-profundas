# Chevrolet Montana 2019 – Resumo Técnico

**Visão Geral**
A Chevrolet Montana 2019 é uma picape compacta de cabine simples, derivada da plataforma do Onix, voltada a usos comerciais leves, com bom equilíbrio entre manobrabilidade urbana e capacidade de carga.

## Desempenho e Motor

- Motorização: 1.4 EconoFlex 8V, 1.399 cm³, 4 cilindros em linha, flexível etanol/gasolina[^1]
- Potência: 99 cv (etanol) / 94 cv (gasolina) @ 6.000 rpm[^1]
- Torque: 13,0 kgf·m (etanol) / 12,9 kgf·m (gasolina) @ 3.800 rpm[^1]
- Transmissão: manual de 5 marchas[^1]
- Tração: dianteira (4×2)[^1]


## Consumo (Inmetro)

- Cidade: 7,5 km/l (etanol) / 11,3 km/l (gasolina)[^1]
- Estrada: 8,4 km/l (etanol) / 12,6 km/l (gasolina)[^1]


## Dimensões e Capacidades

| Item | Valor |
| :-- | :-- |
| Comprimento | 4.514 mm[^1] |
| Largura | 1.700 mm[^1] |
| Altura | 1.572 mm[^1] |
| Entre-eixos | 2.669 mm[^1] |
| Tanque de combustível | 49 L[^1] |
| Capacidade de carga útil | 735–765 kg¹ |
| Volume da caçamba | 1.152 L[^1] |

¹ Conforme configuração de ganchos e revestimento opcional.
