## Principais Insights

### Ferramentas Open Source com Maior Potencial

1. [Penpot](https://penpot.app) (33,400+ ⭐) - Líder em design colaborativo open source, com planos para suporte IA
2. [Onlook](https://github.com/onlook-dev/onlook) (25,600+ ⭐) - Editor visual com IA configurável
3. [Goose AI](https://github.com/block/goose) (19,500+ ⭐) - Única ferramenta open source com integração Gemini nativa

### Melhores Ferramentas Prompt-to-UI

 Por nível de gratuidade:

- [Firebase Studio](https://firebase.google.com/products/genkit)  Grátis via Firebase com Gemini nativo
- [Bolt.new](https://bolt.new) 1M tokens/mês gratuitamente
- [Visily](https://www.visily.ai) Wireframes com IA, apenas marca d'água

### Integração Gemini

Apenas 3 ferramentas oferecem integração nativa:

- [CraftUI](https://ai.google.dev/competition/projects/craftui)  Projeto oficial do Google[^7]
- [Firebase Studio](https://firebase.google.com/products/genkit)  Plataforma completa[^4]
- [Goose AI](https://github.com/block/goose)  Open source configurável[^3]

### Recomendações por Caso de Uso

- 🔓 **Para liberdade total**:  [Penpot](https://penpot.app) - Design colaborativo sem limitações

- **Para IA + Open Source**: [Onlook](https://github.com/onlook-dev/onlook) - Editor visual configurável

- **💎 Para Gemini**: [ rebase Studio](https://firebase.google.com/products/genkit) - Integração nativa gratuita

- **⚡ Para desenvolvimento rápido**: [Bo .new](https://bolt.new) - Full-stack com 1M tokens

- **📐 Par wireframes IA**: [Visily ](https://www.visily.ai) - Text-to-wireframe com marca d'água apenas
